## Install outskirts

The extension runs the `outskirts` command line tool. Install it with Homebrew:

```sh
brew install tiny-earth-moon/tap/outskirts
```

**Open Terminal with the Command** types it in a terminal for you to review and run. If outskirts lives outside your `PATH`, set `outskirts.path` to its location. This step completes once the extension finds the executable.
